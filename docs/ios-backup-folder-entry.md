# 共享文件夹的备份管理入口 — 2026-11-06

设置 → Storage → Shared Folders 中，将旧 Memory 目录入口替换为“备份文件夹”，连接实际的 `MinisFileProvider/Backups` 本地备份目录。

## 行为

- 按时间倒序显示完整 `.minisbak` 文件的名称、大小和修改时间。
- 点击备份进入现有恢复检查；菜单支持分享、删除，左滑也可请求删除。
- 删除前显示文件名和不可撤销提示，仅删除选中的本机文件。备份历史、当前聊天和记忆、其他目的地的副本保留。
- 删除失败显示错误；加载和删除期间禁用文件操作。删除后更新列表，并通知 Files App 刷新。
- 支持下拉刷新、返回前台刷新、备份完成刷新，以及 Files App 可见性开关。
- 备份目录不挂载到 Agent，不加入 `@` 文件候选，不作为共享文件再次备份。

| 旧 `minis://memory` 链接、文件预览、路径映射、挂载与迁移 | 历史文件兼容，保留；没有增加新的旧目录入口 |
