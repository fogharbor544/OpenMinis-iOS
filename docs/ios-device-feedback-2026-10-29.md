# iOS 试用反馈修复与灵魂设置分析（2026-10-29）

本轮仅修改本地文件，没有提交、推送或生成新 IPA。现有已下载 IPA 不包含这些改动。

## 已实现的修改

1. **重签名启动保护**：主程序的记忆、技能、共享文件、连接器配置目录在缺少 App Group 时改用应用私有目录；跳过 App Group 迁移和 FileProvider 注册。原代码在这些路径强制解包容器 URL，缺少 entitlement 时会触发崩溃。修复这个明确缺陷不等于已确认用户设备上全部闪退原因。
2. **连接器**：界面中的 MCP 集成、会话 MCP 和 Bot MCP 入口改称连接器；协议标识、配置文件和 CLI 名称保持技术兼容。内置能力仅列出已实现的文件、日历、提醒事项、照片、相机、音乐、家庭、健康、时钟/闹钟、通知、地图和天气。
3. **系统授权**：日历、提醒事项、照片、相机、音乐、通知、闹钟直接请求系统授权；文件复用系统文件夹选择与挂载管理；已处理过的授权通过公开的系统设置入口管理。返回前台重新读取状态。照片有限授权、日历仅写入和静默通知单独显示。家庭通过 HomeKit 状态回调刷新。健康读取权限无法查询，显示管理提示，绝不显示虚假的“已开启”。地图/天气标明无需独立授权，定位权限另作提示。
4. **Bot 与会话**：引导最后一步进入 Bot/群组页；新建会话先选择 Bot。普通新建、快速操作、分享入口都经过选择页；取消不创建会话。Bot 页通过主导航打开聊天。移除新建按钮按模型组直接创建独立会话的菜单。快捷指令增加 Bot 选择；定时任务的新会话、复制会话继承来源 Bot 和群组记忆边界。未绑定 Bot 的记录保留，但不能继续发送；无归属的远端副本也不会创建。
5. **图标**：Bot 页设置按钮使用与主界面相同的 gear，历史按钮改为返回箭头。创建/编辑 Bot 可选照片或 16 个 SF Symbols 图标，图片裁切为 192×192 JPEG 后保存。默认优先使用最少出现的内置图标，用完一轮再复用。
6. **定时任务中文**：补齐页面标题，管理列表复用详情页的本地化状态、触发时间与重复规则；星期和时长随应用语言设置。

## 冗余设置清理（用户确认后实施）

- 连接器中移除文件入口，保留现有文件管理位置。
- 移除独立灵魂编辑页、设置入口、深链目标和 minis-config 字段；系统提示不再读取全局 SOUL。名称、指令、消息头头像来自当前 Bot。旧文件、旧备份解码和同步兼容代码保留，不删除历史数据；新备份不再提供灵魂分类。
- 技能和连接器选择保存到 Bot，自身私聊与群聊共用同一配置；会话页是该 Bot 配置的快捷入口。旧 canonical 会话选择在首次使用时归入 Bot。
- 长期记忆开关属于 Bot／群组；移除全局开关和运行时独立会话开关。旧 Bot 从 canonical 会话采用旧值，旧群组从排序后的首个成员会话采用旧值，随后只使用 owner 设置。编辑器也保留这一旧值。关闭会同时停止读取与写入，不删除记忆内容。
- 启动选项仅保留 Bot 与群组、上次会话。当前会话模型是独立选择，编辑 Bot 默认模型不会覆盖已有会话。
- 系统应用权限管理集中在内置能力页；系统授权与工具许可分别显示。工具许可仍是所有 Bot 共用的本机策略，不冒充 iOS 授权。位置与剪贴板保留在权限页。
- 子代理、记忆总览、模型组／供应商、同步和备份保留。
