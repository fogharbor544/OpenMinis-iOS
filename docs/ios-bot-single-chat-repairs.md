# iOS 单聊天分支修复

分支：`codex/bot-single-chat`；修改基线：`28c9a17`。本轮仅修改 iOS 实现、相关测试与实施记录；不删除开发机或设备数据，不提供旧数据迁移。

## 产品与备份边界

- 新建工作区没有默认 Bot，所有 Bot 均由用户创建，允许编辑、删除。
- 移除指挥官身份、启动补建、专属提示词、删除限制及 Bot 间委派。`subagent_task` 保留通用 `agent`，未知参数及未知 action 正常拒绝，不降级执行。
- 普通 Bot 继续复用唯一主聊天；群组会话归属、通用子代理队列／停止／超时／结果回传和定时执行基础保留。
- 当前新备份为 `minisbak/3`，Bot 归档为版本 `2`。恢复检查与预览均拒绝不支持的格式，不转换旧备份。
- 恢复保留 Bot 排序、配置、会话绑定、群组和记忆。已有同 ID Bot／群组绑定不同主聊天时明确拒绝，不能合并出两个主聊天。恢复不启动群组轮次或重放操作。
- 浏览器、凭据、通用子代理和定时任务不扩展原有备份范围。Keychain 密码不加入 Bot 归档。

## 界面与安全输入

- 浏览器通过包含 VM 的 sheet item 展示，先设置正确会话，复用同一个 WebView；无记录显示本地起始页，无法获得标签时显示重试。
- 转发选中 manager 的状态变化，覆盖地址、加载、失败与安全输入界面；保留原页面及 cookie store。
- 聊天标题按实际导航容器宽度约束；输入占位包含等待状态，浮动按钮使用实际工具栏高度。拖动／减速时不强制跟随，历史占位不逐条播放动画。
- Bot 入口使用原生推入、一次轻触感及可关闭的轻按动画；能力页统一系统授权与工具许可，权限页仅跳转，通用子代理设置保留。
- `browser_use(action: secure_input)` 使用原生卡片输入密码、PIN、验证码。展示网站、请求 Bot、用途；模型仅取得引用与状态，原始输入不进入消息或工具结果。
- 安全输入期间暂停模型浏览器访问和页面预览保存；取消／超时／后台释放临时值。结束前清空表单并刷新同一 WebView，成功清理后才恢复模型访问，失败可重试。
- 网站本身必须收到用户授权填写的值；该通道不是对恶意网站的隔离机制，不承诺网站永远不会在响应中回显提交内容。
- 密码由用户确认登录成功后选择保存或更新 Keychain；PIN、验证码不保存。认证取消或写入失败不显示成功。导入仅显式单向读取，不自动迁移、不回写源文件。
