# Bot 团队、原创头像与新备份格式

开发基线：`7450d01`。独立分支：`codex/bot-team-original-avatars`。

## 使用流程

- 首次打开自动创建“指挥官”，固定身份 `builtin-commander`。用户可以修改名称、头像和配置；删除入口和存储层均保护该身份。首页单独展示指挥官。
- 在指挥官中明确要求创建助手时，`bot_create` 保存真实 Bot 配置、职责指令、自我介绍和可选偏好题，并返回可打开的链接。同一会话的同一次工具请求不会重复创建。
- 新助手首次打开显示介绍和偏好多选。可以多选、跳过或直接聊天。选择仅用于长期记忆，不执行任务或创建计划；关闭记忆时不保存所选偏好。
- 指挥官通过 `bot_task` 将适合的需求交给专职 Bot。每个任务使用独立、隐藏的子会话，沿用该 Bot 自己的配置、能力和记忆范围；不读取它的私人聊天历史。
- 同一专职 Bot 的委派按顺序启动，等待它已有的会话工作完成，并遵守父会话并发和排队上限。排队中的补充信息不会改变原排队顺序。
- 指挥官会话显示“发消息给 / 消息来自”，专职 Bot 显示来自指挥官的任务。点击可查看只读的两个 Bot 间会话；返工仍保留之前的入口。
- 返回结果进入待核查状态。指挥官检查结果及实际来源后完成交付；允许一次具体返工。活跃期间连续两分钟无进展会追问，再过两分钟仍无进展则取消，并等待原任务实际停止后通知指挥官接手。排队、后台和系统挂起时间不计入无进展时间。
- 发送、付款、删除等操作复用已有 `user_ask` 确认流程。另一个 Bot 的输出不能作为用户授权。专职 Bot 不能递归委派，也不能把其他 Bot 的输出写成用户长期偏好。

## 头像与会话界面

十二个原创柔软立体伙伴：云朵小熊、薄荷水獭、奶油小羊、星空猫头鹰、蜜桃垂耳兔、琥珀小狐狸、糯米小海豹、莓果水豚、葡萄小浣熊、雨滴小鸭、绒球羊驼、月牙小猫。

资源使用稳定 ID 和版本 1；每个角色有 16 帧、约两秒的一次动作。新建和编辑共用头像选择器，保存时仅提交头像字段，保留其他同时发生的配置修改。现有系统图标、相册头像继续可用。列表显示静态封面，主预览出现或轻点时播放一次；离屏、进入后台、低电量或减少动态效果时停止。

每次逻辑回复使用圆角会话块，长回复继续拆分为多个 collection view 单元，避免退回到超长单元。一个会话只显示一条稳定的新消息分界线。右滑可引用整条用户消息或助手可见正文，也可使用菜单引用；输入框可以取消或更换引用。超长引用最多保留 12,000 字符。引用保存作者、来源 ID 和文本快照，并随数据库、同步、备份、搜索及导出传递。引用正文作为数据传给模型。

## 备份与恢复约定

仅支持 `minisbak/4` 和 Bot 归档 v3。旧的 `minisbak/3`、Bot 归档 v2 在检查和导入时明确拒绝，旧文件保留。

完整备份包含 Bot 配置、顺序与置顶、指挥官身份、记忆及授权/遗忘标记、引导状态、头像、私人/群组/委派会话、来源、引用、回复分组及已读状态。仅配置备份去除会话、委派、已读位置及历史来源跳转，保留配置、有效记忆和引导偏好。

内置头像只保存资源 ID/版本，自定义照片保留实际字节并做校验。缺失的内置资源回退到系统图标并报告；损坏的照片在写入前拒绝。

导出先在短写入屏障下冻结工作区、记忆和 SQLite 快照；后续导出及断点续传始终读取同一份快照。未完成或选项不匹配的快照不能用当前数据继续拼接。私有快照目录不会进入最终 ZIP、加密文件集或校验文件集，仅配置备份也不复制完整聊天数据库。

恢复在写入前检查格式、完整性、所有权和冲突。相同 Bot 保留本地配置，追加不冲突历史；不同主会话或所有权冲突会拒绝。仅替换尚未使用的默认指挥官占位，不复制第二个指挥官。重复导入保持幂等，并保留遗忘/撤销结果。

聊天与 Bot/记忆数据作为相关恢复单元建立持久检查点。失败或应用重启时通过检查点回滚，SQLite 恢复保留现有连接有效性；同步和新任务在恢复期间等待。其他备份分类保留各自处理方式。

恢复后的排队、执行中和接手中任务统一变成“已中断”，清除旧任务 ID，不自动回调、唤醒模型或执行工具。旧待确认请求在成功提交恢复后丢弃，历史授权不能直接复用。用户明确要求继续时创建新的执行尝试，保留与旧记录的关联。Bot 明确配置的模型组不可用时停止解析，不悄悄改用全局模型。

## 验证边界

自动化验证包括真实生产 Store/Archive 的持久化、归属、冲突、重复恢复及双设备往返；生产命令处理的创建去重、状态转换、一次返工、排队上限和恢复边界；SQLite WAL 冻结/续传/回滚；原生头像组件的解码、播放生命周期及浅色、深色、大字号截图；现有安全输入、记忆、群组、模型恢复、同步游标及界面回归；完整未签名 iOS 构建。

原生命令测试在模型和任务边界使用替身，不调用真实供应商。头像截图使用实际头像组件，不代表整个应用的端到端导航。测试结果以当前分支 Actions 记录为准。

设备验收仍需覆盖：真实模型的自动匹配和来源核查；长任务追问与实际停止后的接手；引用手势与返回、文本选择、表格横滑的组合；系统减少动态效果/低电量切换；真实数据恢复的断电与磁盘错误注入。未运行的项目不能视为已通过。
