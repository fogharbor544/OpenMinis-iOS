# iOS 浏览器备份与迁移盘点

2026-11-07。适用于当前 iOS fork 的本机 `.minisbak` 备份和合并恢复。

- 浏览器书签是独立类别。按 ID 合并，目标机已有记录和顺序保留；新增条目追加到末尾。恢复前验证网址，写入成功后更新内存列表。
- 浏览器密码和 Cookie 各自独立，默认不选，必须加密并验证设备所有者。两个备份成员分别认证，只在内存中解密。
- `shared/password_manager/vault.json` 是共享账号的权威来源。浏览器密码直接从该文件读取共享账号，跳过 Keychain 同步副本；共享文件类别不重复保存。恢复按 HTTPS 站点和账号合并，目标机的共享库与本机账号都优先。新增共享账号写回共享库，解锁密码管理器后继续同步；其他账号写入 Keychain。迁移的是账号记录，不复制外部文件授权或源 JSON 的其他内容。旧包在共享文件中携带的密码库也按账号合并。
- Cookie 从源设备的 WebKit 存储读取。恢复时同时保留目标机 WebKit 和仍有效的本地 Cookie 恢复缓存；过期和重复项单独提示。分区 Cookie 不写入迁移包，也不再写入不能表达分区的本地缓存。服务端失效或设备绑定仍可要求重新登录；浏览历史和其他网页存储不在范围内。
- 聊天导出要求 SQLite 读取完整；没有数据和读取失败会得到不同结果。仅当清单证明流为空且未声明相应文件时，旧包才可以省略 JSONL 流。
- 加密前先验证和封装浏览器敏感数据。开始原地加密前撤销续备入口；旧版本遗留的中断暂存目录需要重新生成，不影响已保存的备份包。
- 旧备份里的共享密码库如果无法解析或合并，只报告该项失败，保留已恢复的普通共享文件。
- 新备份即使选了聊天但没有会话或消息，也会保存对应的空数据文件，避免在恢复其他类别前因为缺少会话文件而中止。
- 类别是同一格式下的新增项；现有 `minisbak/4` 包无需转换，之前没有写入的浏览器数据需要在原设备重新备份。

| 候选项 | 当前情况与建议 |
| --- | --- |
| MCP OAuth | `BackupExporter.writeSecrets` 会写入 MCP OAuth 凭据；`BackupImporter.importMCPServers` 单独恢复时只处理配置。优先让 MCP 类别独立合并自己的凭据，继续保留目标机已登录的账号。 |
| 外观与输入偏好 | `AppearanceSettingsView` 和 `FontSettings` 有独立的持久设置。适合新增少量白名单项，例如主题、字体、界面语言和输入行为。设备锁定、权限和内部标识应由目标机自己设置。 |
| 定时任务定义 | `AgentJobRegistry` 是进程内状态，目前重启不恢复。若加入备份，先分离可持久化的任务定义；导入默认暂停，让用户核对目标 Bot、会话和工具后启用。运行历史和运行中的任务无需迁移。 |
| 挂载目录配置 | 可以迁移显示名称等配置，但本地文件夹的授权需要在目标机重新选择。外部挂载的文件应由原存储备份。 |
| 浏览历史与网页数据 | 历史可作为可选类别，优先级低。网页本地存储与运行状态不随 Cookie 恢复。 |

2026-11-08 补充：SQLite 查询必须完整完成，但单条消息解码失败不再阻止导出其余记录。未写入的消息数随清单保存，在备份结果、日志和恢复时提示；不修改源聊天，也不把空白消息写进包中。

2026-11-08 真机后续：会话列表读取可能在任何消息解析前失败。SQLite 备份复制会保留 WAL 模式，在不允许锁和 sidecar 文件的只读连接上可复现打开查询失败；现在仅对副本切换日志模式，让快照可独立读取。旧表中没有稳定 ID 的行不再阻止导出其他会话，会单独报告数量。真正的会话查询错误附上 SQLite 编号，仍不会出具空备份。

审查后续：启动时清理不兼容的旧暂存；新备份也会在写入新标记前清理旧暂存。按完整字节读取会话 ID，遇到嵌入空字节或无效 UTF-8 时作为不可用记录报告，避免导出重复会话。
