# iOS 视觉统一（2026-10-31）

## 统一规则

- 采用现有 iOS 分组列表和系统背景，保留系统卡片圆角与导航外观。
- 正文使用 `.body`，行内状态使用 `.subheadline`，说明与运行状态使用 `.footnote` / `.caption`。颜色使用系统语义色；重要的未授权状态保持主文字颜色。
- 复用原设置页的 21pt 圆形徽标与 9pt 白色 SF Symbol。公共组件位于 `Views/ContentView/Support/SettingsRowStyle.swift`，同时服务设置、资料、内置能力、技能详情和备份动作。
- 短值靠右；长值和辅助功能字号下的值移到标题下方，保留自然换行。指令预览最多两行，完整内容仍通过原编辑入口查看。
- 控制区使用至少 44pt 点击目标，卡片内容以 16pt 水平间距、4/8pt 小间距组织。装饰性图标不进入 VoiceOver 阅读顺序。

## 四处页面修改

### 设置

供应商、模型组、用量与运行时、外观等项目使用相同的图标规格。集中复用已有图标样式，取消重复定义；列表显式采用系统 inset-grouped 样式。

### 聊天

Bot 名称独占导航栏标题，点击仍打开资料。模型、连接状态与运行状态组成下方控制区，模型选择和思考等级具有独立点击目标。模型的提供商、实际模型、快速模式和额度提示保留。

控制区、定时任务、搜索、错误与临时提示仍共用一个顶部安全区域占位，保留消息视口裁切。输入区尺寸测量、键盘避让和自动跟随策略不变。非 Bot 聊天保留原导航标题路径。

导航标题在固定导航栏内限制最大视觉字号；正文、设置与资料内容继续随辅助功能字号增长。回退提示遵循减少动态效果设置。

### Bot 资料

使用明确的页标题、72pt 头像和系统标题字号。配置与会话控制复用设置行。浏览器的标题、选项和访问入口整合在系统卡片中；没有预览时显示紧凑的文字入口，有预览时显示 140pt 裁切缩略图。原终端、刷新、模型、记忆、文件、会话动作及锁定条件保留。

### 内置能力

能力名称与系统授权状态共用自适应设置行；图标规格与设置/资料一致。工具调用策略仍独立管理，窄屏或大字号时菜单移至下一行。单张卡片拥有完整内缩分割线，说明文字置于无额外卡片的系统背景上。

## 验证边界

本地源码约束与语法检查，以及云端编译、原生组件渲染的实际结果，在完成后记录于下方。新增原生渲染检查仅覆盖实际复用的设置行组件，包含 320/375/667/1024pt、浅深色和标准/AX5 字号；不代表完整页面、VoiceOver 操作、键盘或真机滚动验收。

完整页面待验收：在聊天中发送/停止/继续、切换模型与思考等级、弹出/收起键盘、搜索并滚动；从聊天及首页打开资料，修改指令/模型/开关，使用浏览器和终端；在系统设置返回后检查授权刷新。分别检查浅深色、横竖屏和最大字号。
