# iOS 功能改造

这些功能复用 OpenMinis 的聊天引擎、模型组、Skills、MCP、设备权限和任务调度器。Android 与共享后端未修改。

## 使用入口

- 默认首页显示 Bot 与群聊；“历史”可回到原有会话列表，原会话保留。
- 创建 Bot，设置名称、指令和模型组。打开一次 Bot 后，可在编辑页面配置该会话的 Skills 与 MCP。
- 至少创建两个 Bot 后可创建群聊，并调整成员顺序。发送时可选全部成员或单个成员；每次发送仅执行一轮，成员依次回复，后面的成员可读取前面的回复。“停止”取消当前调用和后续成员。
- 每个群聊成员使用独立的普通 OpenMinis 会话，不带入 Bot 私聊历史。群聊共享最近 30 条消息；回复下方可打开工具执行记录及完整成员会话。
- 内置浏览器工具栏提供书签和密码入口。书签支持新增、编辑、删除和重新打开。
- 密码需经设备认证解锁，可手动新增或从当前登录页面读取并确认保存。按 HTTPS 网站来源匹配，包括非默认端口；填充前再次认证，填入后由用户确认登录。
- 设置中的“定时任务”统一列出当前注册的非即时任务，可查看详情、修改计划和提示词、暂停/启用及删除。运行中的任务不能编辑。
- MCP 入口中的“内置能力”列出核心工具、全局开关、配置入口和 28 个公开原生命令；已有权限开关直接使用执行时的权限存储。

## 当前边界

- 密码保存在当前设备 Keychain，需要设备密码；不作为供其他 App 使用的密码提供程序，不同步密码。
- 网页填充支持主页面的单一密码输入框；iframe、Passkey 和多步骤登录可能需要手动输入，不自动提交表单。
- Bot 配置与群聊共享记录保存在本机。删除 Bot 保留既有会话；删除群聊会删除共享记录，但保留成员会话。
- 定时任务沿用项目现有的进程内调度方式。退出或重启应用后不会恢复任务；这次改造增加管理入口，不增加系统后台调度服务。
- 原生能力仍受 iOS 系统授权、设备硬件和前台运行要求限制。

## 验证

GitHub Actions 的 `iOS validation` 工作流运行 Swift 语法检查、原有定时任务回归、Bot 存储、浏览器存储、定时任务编辑和群聊调度行为测试。

行为测试编译实际存储或调度代码，使用临时目录及受控认证、密码存储、计时器、聊天引擎替身。它们不替代真实 Keychain、WKWebView、模型服务和设备交互测试。

手动运行工作流并启用 `full_build`，会构建原生依赖和未签名的 iOS 应用。安装到 iPhone 仍需有效签名及设备配置。

真机验收应覆盖：书签重启保留；认证取消与后台锁定；匹配/不匹配网站填充；两个 Bot 的工具调用、协作、失败和停止；任务编辑及触发；MCP 权限变更后的实际调用行为。
