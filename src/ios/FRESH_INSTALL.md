# 全新产品的数据结构

此 iOS 分支尚未发布，没有需要升级或迁移的历史数据。本次清理以新安装为基准，不提供上游旧版本的数据迁移。

## 已移除

- 全局与每日 Markdown 记忆：工具、提示词注入、管理页面、按正文撤销、同步类型、文件扫描及旧记忆备份。
- Bot 单会话格式补全和会话归属推断；新格式明确保存 `conversationIds` 和 `sessionOwners`。
- V1 云同步引擎、历史迁移引擎、迁移进度页面、历史批量回填和旧整文件配置同步。同步页仅显示当前状态和手动同步入口。
- 模型配置和单例 OAuth 凭据迁移、旧 Keychain 读取回退、旧模型 ID 映射及降级开关。模型条目统一使用 `providerInstanceId/modelId`，数据库、同步、引用保持一致。
- MCP 配置、工具输出目录和浏览器 Cookie 的旧位置迁移。
- 聊天数据库、模型数据库的旧字段补齐与回填；完整字段直接定义在初始建表语句中。
- 旧压缩标记的加载回退、旧查询回退及标记升级逻辑。
- 废弃用户授权设置清理。

## 保留的当前功能

- Bot 设定、每个对话的上下文、独立长期记忆条目、用户主动共享。
- 删除后的归属与防恢复标记。这些是新产品运行时的数据语义，不是旧版本兼容。
- 当前 iCloud 同步、用户主动备份恢复、角色设定及其头像备份。配置备份合并已从旧同步引擎提取为 `ProviderBackupMerger`。
- iOS 更新导致应用容器路径变化后的挂载修复、模型 API 差异处理、当前工具输出占位符识别、网络失败处理。
- 当前配置的本地快照和正常可选字段；没有将所有缺省值或错误恢复误当成历史迁移删除。

长期记忆条目尚未提供云同步或备份，本次没有新增这两项能力。

## 验证

- 本地执行 `check_fresh_install.py`：从空 SQLite 创建聊天库和模型库，再次打开、验证字段并写入聊天／压缩／同步记录。
- 本地对修改的 Swift 文件进行语法初筛，与修改前源码比较解析器不支持的语法；不能代替 Xcode 类型检查。
- CI 已加入全量 Swift 解析、当前模型 ID 往返测试、扩展的 iOS 16 页面类型检查，并保留 Bot 记忆、会话、浏览器与定时任务测试。
- 本次 GitHub Actions 未能启动：账户付款或支出上限阻塞。此次变更尚未通过 Xcode 编译或真机验收。
